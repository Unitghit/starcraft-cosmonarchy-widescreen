# StarCraft Cosmonarchy Widescreen 0.3.0

This is the first public release candidate of the Cosmonarchy expanded viewport
and resolution configurator.

## Highlights

- One portable `Cosmonarchy Widescreen Settings.exe`; place it beside
  `Cosmonarchy BW.exe`.
- Independent internal gameplay resolution and external presentation size.
- Supported 16:9 presets through 2560x1440 and 3840x2160 (4K).
- Custom internal dimensions from 640x480 through 3840x2160.
- Windowed, borderless fullscreen, exclusive fullscreen, display selection,
  exact output, fit-to-display, rational scale, and nearest/smooth filtering.
- Resolution-derived rendering, input, HUD, minimap, placement, overlays,
  camera, tooltip, portrait, and positional-audio behavior.
- Verified backup/restore and strict compatible-build checks; GPTP is never
  modified or distributed.
- Stable middle-mouse panning without stale transparent map bands.

## Important 4K note

True 3840x2160 internal rendering can take several minutes to enter a match.
This is an engine-side cost of dozens of sequential StarCraft render passes,
not external scaling. For a much faster 4K-sized result, choose 1920x1080
internal resolution and 2x external scale.

## Installation

Download the official ZIP bundle and `SHA256SUMS.txt`, verify the checksum,
extract the bundle, place the executable beside `Cosmonarchy BW.exe`, then
choose **Save** or **Save & Play**.
Use **Restore Original** to close the game, return the backed-up renderer and
pre-install cnc-ddraw settings, and remove generated widescreen files. The
configurator executable remains so it can be run again or deleted manually.

The source archive generated by GitHub contains the complete release source,
build scripts, diagnostic tools, and engineering system map. No game files or
game assets are included.
